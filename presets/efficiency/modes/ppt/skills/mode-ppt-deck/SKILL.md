# 做一份能讲的幻灯片

这份是「效率模式 · PPT」的默认做法。目标不是好看，是**上台能讲、投出来能看清、改起来不返工**。
顺序是死的：定场合 → 定页数 → 找模板 → 一页一个信息点 → 字号留白 → 导出自查。

## 一、开工前先问清五件事（一次问完，不要边做边问）

1. **给谁看**：老板 / 客户 / 同事内部。决定用不用敬语、要不要结论前置。
2. **讲多久**：10 分钟约 8–10 页；30 分钟约 20 页。按「一分钟一页」估，宁少勿多。
3. **要几页**：页数是硬约束。用户说 3 页就是 3 页，不要用附录偷加。
4. **投在哪**：会议室投影（16:9，对比度要大）还是自己电脑（可以密一点）。
5. **要不要可编辑**：交付 pptx 源文件，还是只要 PDF／图片。决定用不用自定义图形。

问不到就按默认：16:9、内部汇报、20 分钟、交付 pptx。把默认值写进回执，别默默替用户决定。

## 二、模板与母版：先找现成的

- 先看用户给的模板、公司模板、上一次的稿子。**能在原模板上改，就不要新建。**
- 用模板时只动版式里的占位符，不要在母版上贴手动文本框——用户一换版式就全乱。
- 主题色最多 3 个：一个主色、一个强调色、一个中性灰。标题与正文用同一套，别一页一个颜色。
- 中文字体先确认装没装。Windows 上稳妥的是「微软雅黑 / Microsoft YaHei」；macOS 是「苹方」。**字体名写死英文名**，中文名跨机器容易回退。
- 设置字体时同时写 `a:latin` 和 `a:ea`（东亚字体）；只写 latin，中文会回退成宋体。

## 三、结构：每页一个信息点

- 标题不是标签，是**这一页的结论**。写「三件事，两件在轨」，不写「进展汇报」。
- 一页只讲一件事。要讲第二件就再拆一页；拆页比缩字号便宜。
- 正文最多三条支撑，每条一行说完。第四条出现时，先问它是不是下一页的标题。
- 能画图就别列表，能列表就别写段落。整页超过 80 个汉字，基本就是没提炼。
- 封面页也要有信息点：讲什么、给谁、什么时候。别只放一个公司名。
- 最后一页给明确的下一步：谁、做什么、什么时候。不要用「谢谢观看」占一页。

## 四、字号、行距与留白下限（硬线，不许破）

- 标题 >= 28pt，封面主标题 >= 40pt。
- 正文 >= 18pt，表格与图注 >= 14pt。
- 行距 1.15–1.3；段间距 >= 6pt。
- 四边留白 >= 0.6 英寸；元素之间 >= 0.3 英寸。
- 一页字塞不下只有两个动作：删内容，或拆页。**不许缩到 16pt 以下。**

## 五、图形与表格

- 图形只用矩形、线条、圆三种；装饰元素不要超过两种颜色。
- 表格直接嵌原生表格，不要截图贴图——截图以后没法改。
- 数据图先问「想让人看到哪一个数」，再选图型；一张图只表达一个结论，坐标轴从 0 开始。
- 图标与图片要嵌进文件，不要链接外部路径，换台机器就裂。

## 六、交付前：导出成图，自己逐页看一眼

这一步不能省。看不到成图，就不算做完。

1. 导出：`soffice --headless --convert-to pdf` 再转 PNG；或先导 PDF 逐页看。
2. 逐页看四样：**文字溢出框没有、元素有没有错位、有没有空白页、字体有没有回退成宋体**。
3. 投影尺寸自查：把页面缩到 25% 看，还认得出的才是能投的。
4. 文件自查：pptx 能被 python-pptx 正常打开、页数对、没有修复提示。
5. 交付物：pptx 源文件 + 一版 PDF 或截图。两个都给，别只给源文件。

## 七、常见坑

- 中文粗体在部分字体上没有真粗体，会被合成糊掉；标题优先换字重，不靠 bold。
- 文本框默认会自动缩放，关掉它（`auto_size = None`），否则排版到别的机器会跳。
- 形状默认带阴影，逐页关掉，不然一圈灰边很难看。
- 从网页或聊天记录复制文字会带一堆样式，先粘成纯文本再排。
- 用 python-pptx 生成时，`add_textbox` 不会自动换行，必须 `word_wrap = True`。
- 最后一页页数与字数再核一遍：用户要 3 页，交付就只能是 3 页。

## 八、验收（自己先过一遍再交）

- [ ] 页数 = 用户要的页数。
- [ ] 每页标题是结论句，不是标签。
- [ ] 最小字号 >= 14pt，正文 >= 18pt，留白 >= 0.6 英寸。
- [ ] 导出成图看过，无溢出、无错位、无空页、无字体回退。
- [ ] pptx 能打开、页数正确；同时给了 PDF 或截图。
